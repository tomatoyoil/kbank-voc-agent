# 케이뱅크 일반 이체 송금 플로우 (S0~S8)

> 출처: 케이뱅크 앱 송금 화면 캡처 10장 (`input/captures/01~10.jpg`)
> 화면에 보이는 정상 경로만 적었다. 예외 처리와 VOC 내용은 넣지 않는다.
> 화면 요소는 캡처에 보이는 텍스트·버튼·아이콘을 빠짐없이 옮겼다(2026-10-25 전수 기록). 해석 없이 화면 그대로 적고, 의미가 불분명한 요소는 "(라벨 없음)"으로 표시했다.
> 캡처의 개인정보(이름, 계좌번호, 잔액)는 일반 명칭으로 바꿨다. 상단 상태바(시간, 배터리)는 제외했다.
> 범위 외: 해외송금, AI 이체(S2의 진입 버튼만 표시), 계좌 잠김

| 단계 ID | 단계 | 캡처 | 화면 | 화면 요소 (전수) |
|---|---|---|---|---|
| S0 | 앱 실행·로그인 | 01 | 보안 로그인 "간편비밀번호를 입력해주세요" | 우상단 더보기(···) 아이콘, "보안 로그인" 자물쇠 라벨, 간편비밀번호 6자리 입력 표시, "비밀번호를 잊어버렸어요" 버튼, "로그인 상태 유지" 체크박스와 ? 도움말 아이콘, 숫자 키패드(무작위 배열), 얼굴 인증(Face ID) 아이콘 키, 지우기(←) 키 |
| S1 | 이체 진입 | 02 | 홈 | "홈" 타이틀, "사장님" 칩, 알림 벨 아이콘(배지 숫자), 계좌 카드(통장 이름, 계좌번호, 복사 아이콘, 한도제한 배지, 더보기(⋮) 메뉴, 잔액), 가져오기 버튼, 이체하기 버튼, 카드 사용액 배너(넘김 점 표시), 바로가기(내 자산, 자동이체, 자동충전, 편집하기), "내 자산" 영역(편집 버튼, 카드, 내 자산 모두 보기), 하단 탭(홈, 상품, 혜택, 서비스, 전체) |
| S2 | 받는 곳 선택 | 03 | "어디로 돈을 보낼까요?" | 뒤로가기, 계좌번호/휴대폰번호 탭, 계좌번호 입력칸, 안내 말풍선 "계좌 순서와 이름을 편집해보세요"(닫기 X), 즐겨찾는 계좌(편집하기, 즐겨찾기 별 표시 계좌 카드, 계좌추가), 내 계좌(다른 은행 계좌 불러오기), "이체를 도와주러 온 AI" 진입 버튼 |
| S3 | 계좌·기관 입력 | 04, 05 | 계좌번호 입력 | 뒤로가기, "계좌번호 입력" 라벨, 계좌번호 입력칸, 은행·증권사 선택 드롭다운, 추천 기관 칩(가로 나열), 선택 후 드롭다운에 기관명 표시, 확인 버튼(기관 선택 후 표시) |
| S4 | 금액 입력 | 06 | 금액 입력 | 뒤로가기, 취소, 출금 계좌 표시("케이뱅크(계좌 끝 4자리) 에서"), 받는 사람 표시("기관명 + 실명 님에게"), 입력 금액 표시와 지우기(X) 아이콘, 금액 보조 표기("1만원")와 밑줄 친 금액(라벨 없음), +1만/+10만/+100만/전액 버튼, 숫자 키패드(00 키 포함), 지우기(←) 키, 다음 버튼 |
| S5 | 내용 확인 | 07 | "OO님에게 N원을 보낼까요?" | 뒤로가기, 취소, 보내는 기관 → 받는 기관 아이콘, 받는 계좌("기관명 계좌번호 로 보내요"), 경고 말풍선 "1년 동안 돈을 보낸 적 없는 계좌예요 계좌번호가 맞는지 한 번 더 확인해주세요"(닫기 X), 받는사람 통장에 표시(편집 아이콘), 내 통장에 표시(편집 아이콘), 보낼 시간 "바로 보낼게요"(편집 아이콘), 부가기능 설정, 보내기 버튼 |
| S6 | 인증 | 08 | 확인 화면 위 인증 | S5 화면 위에 생체 인증(Face ID) 오버레이, 보내기 버튼이 "확인중"으로 바뀜 |
| S7 | 처리 중 | 09 | "OO님에게 N원을 보내는 중이에요" | 보내는 기관 → 받는 기관 아이콘(진행 화살표), 받는 사람, 금액, 받는 계좌("기관명 계좌번호 로 보내요"). 버튼 없음 |
| S8 | 완료 | 10 | "OO님에게 N원을 보냈어요" | 출금 푸시 알림(케이뱅크, "출금 N원", 받는 사람 · 통장 이름(계좌 끝 4자리)), 완료 체크 표시, 받는계좌(기관명 계좌번호), 공유 아이콘, "메세지 보내기" 버튼, 안내 말풍선 "돈을 보냈다고 알려주세요"(닫기 X), 의견 남기기 배너("케이뱅크 이체하기 / 고객님의 의견이 궁금해요"), 추가이체 버튼, 확인 버튼 |

변경 규칙: 2회 실행에서 흔들린 지점(한도·인증)의 예외 화면만 앱에서 직접 확인해 추가. V1~V5 문구·R번호는 넣지 않음. 바꾸는 파일은 transfer_flow.md 하나.
