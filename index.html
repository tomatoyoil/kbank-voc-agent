송금 VOC 문제 발굴 Agent · 결과 뷰어

앱 리뷰 30건(App Store 15, Google Play 15)을 넣으면 송금 단계(S0~S8)별 사용자 문제를 근거 리뷰 ID와 함께 돌려주는 Claude Code 에이전트의 실행 결과입니다. 에이전트는 Claude Code에서 실행했고, 이 페이지는 그 결과 파일(개선 후 실행본)을 보여주는 뷰어입니다.
개인 포트폴리오 프로젝트이며 케이뱅크와 무관합니다.

처리 흐름

리뷰 30건 → ① 유형 분류 → ② 송금 단계 매핑 (범위 외 분리) → ③ 문제 묶기·원인 추정 → 사람 검수 1 (채택·우선순위) → ④ 원문 대조 검수 (반려 시 재실행) → 사람 검수 2 (확정)

분류·매핑·묶기·원문 대조는 AI가, 채택·우선순위·확정은 사람이 합니다. 모든 문제에는 근거 리뷰 ID가 있으며, 단계를 특정할 수 없으면 추측하지 않고 "확인 필요"로 남깁니다.
